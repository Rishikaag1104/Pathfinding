# Pathfinding Comparison on Real-World Maps

A graph-algorithm project that implements and compares **A\***, **Dijkstra's Algorithm**, and **Breadth-First Search (BFS)** for pathfinding on real-world map data from **OpenStreetMap (OSM)**.

## Overview

The project explores how classical graph-search algorithms behave when solving route-finding problems on real geographic data.

It focuses on comparing:

- **A\*** — heuristic-guided search designed to reach the target efficiently.
- **Dijkstra's Algorithm** — shortest-path search without a heuristic.
- **BFS** — level-by-level graph traversal, useful when edges are treated with equal cost.

## What This Project Demonstrates

- Graph traversal and shortest-path algorithms
- Algorithmic trade-offs between uninformed and heuristic search
- Working with real-world map/graph data
- Applying theoretical data-structures and algorithms concepts to a practical problem
- Comparing different approaches to the same pathfinding task

## Data Source

The map data used by the project is obtained from **OpenStreetMap (OSM)**.

## Algorithms Compared

| Algorithm | Core idea | Typical use in this project |
|---|---|---|
| A\* | Uses a heuristic to guide the search toward the destination | Efficient route search |
| Dijkstra | Expands the lowest-cost known node without a heuristic | Shortest-path baseline |
| BFS | Explores nodes level by level | Unweighted graph traversal baseline |

## Project Status

This repository is maintained as an algorithms-focused portfolio project demonstrating pathfinding on real-world geographic data.
